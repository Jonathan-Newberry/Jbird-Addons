# Jbird-Addons

The first item I made for this project was a homing magic item. The item used the base code from the tModLoader github for a homing projectile and a basic magic weapon. I built on the code and increaseed the turning radius to make the homing more accurate, and added code to it bounce between up to three targets in a certain radius
